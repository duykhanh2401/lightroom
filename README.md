# Sắc Độ — Lightroom Color Lab

Website học Lightroom bằng tiếng Việt với 16 bài học, tài liệu PDF, tìm kiếm, bộ lọc và tiến độ lưu trên trình duyệt.

## Bật GitHub Pages

1. Mở **Settings → Pages**.
2. Trong **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn nhánh **main**, thư mục **/ (root)** rồi bấm **Save**.
4. Chờ GitHub hoàn tất xuất bản. Đường dẫn dự kiến: https://duykhanh2401.github.io/lightroom/

Không cần build, cài thư viện hay API key. Mã nguồn website đặt ngay ở thư mục gốc. Tài liệu nằm trong `docs/`.

## Các tính năng

- Đọc 16 bài học trực tiếp trong website.
- Tải PDF từng bài hoặc bộ ZIP đầy đủ.
- Tìm bài theo tên và công cụ, lọc theo nhóm.
- Đánh dấu hoàn thành; tiến độ chỉ lưu trên trình duyệt hiện tại.
- Thực hành quan hệ màu với thanh đổi sắc độ nền.

Font Google có font hệ thống dự phòng. Các tài liệu ngoài vẫn thuộc quyền của tác giả tương ứng; website liên kết tới nguồn gốc.
